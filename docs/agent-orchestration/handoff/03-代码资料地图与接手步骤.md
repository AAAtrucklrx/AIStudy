# 代码资料地图与接手步骤

包内路径以本包根目录为基准。历史记录的本机绝对路径保留作为当时证据，不要求新电脑具有相同用户名或目录。

## 代码入口

- 当前完整工作树：`work/2026-11-15/AIforStudy/`。先看其 README、pyproject.toml、requirements.lock、package.json/package-lock.json 和 config。
- CLI：`src/aiforstudy/cli.py`；流水线：`src/aiforstudy/pipeline/`；当前可执行 Python 包入口为 `python -m aiforstudy` / `aifs`，具体命令以当前 CLI 帮助为准。
- 模型配置及路由：`config/models.json`、`src/aiforstudy/providers/factory.py`、`routing.py`、`gateway.py`、`dsh_account.py`、`dsh_bridge.cjs`。现有 transport 返回完整文本，不是已经接好的教学流式聊天接口。
- 本地配音：`config/narration.json` 与 `src/aiforstudy/blocks/media/`，实际模型/解释器位置经环境变量指定。不要写回原电脑的绝对路径。
- 视频：`src/aiforstudy/core/video_analysis.py`、`video_recognition_worker.py`、`src/aiforstudy/resources/video-analysis/`；实际任务、版本、原片和结果在 `data/video-analysis/`。
- 控制台：`src/aiforstudy/ui/server.py`。已有生产/视频任务路由，不等于已有 Tutor/thread/answer API。
- 阅读器与教学排版：`blocks/render/assets/`、`src/aiforstudy/blocks/render/`。实际成品资产也在最新 delivery 的 book/assets 中，二者要核对，不要只改一个位置就声称发布了。
- 知识来源与正文：`src/aiforstudy/blocks/content/`、`data/study-revision-20261029/`，关注 reader_document、source_inventory、source_context 及已有结论来源记录。
- 媒体生成：`tools/manim_worker/`、`src/aiforstudy/blocks/visual/` 和 media 模块。保持生成代码隔离与实际画面检查，不能通过关闭沙箱绕过能力检测。
- 资料索引：`src/aiforstudy/core/course_library.py`；书架：`src/aiforstudy/shelf/` 与 `resources/shelf/`。当前本机入口只绑定 loopback，不是已部署手机/公网产品。

## 成果与材料

`delivery/复变函数-用途与配音版-20261115/` 是最新教材和媒体；`delivery/视频解析-第一讲-20261115/` 是已有视频讲义导出。工作树 data 同时保留当前任务与来源资料，不能用单个成品 ZIP 替代它。

原始复变教材、线代测试材料、已有考试资料见工作树 data 中的来源与资料库；另附 `补充原始资料/` 中的数值计算教材。先看文件哈希与项目书本标识，不能仅靠同名 PDF 判断版本。

`discussions/` 和 `discussion-audit-20261029/` 保留教学方式与跨任务对抗讨论；`research/` 保留筛选后的研究代码、结果和证据。大模型与下载缓存未放入包内，排除情况见 `交接资料/打包范围.json`。来源记录中的模型仓库、版本和校验值是复现线索，不表示权重已随包提供。

修改教材时另读 [教材增量编辑与重建地图](交接资料/教材增量编辑与重建地图.md)，它说明作者源文件、当前素材、构建参数和独立输出的关系。

## 重要新研究

`research/2026-11-15/embedded-tutor-mobile/` 包含 DeepTutor v1.7.2 固定源码核查、Goodnotes/移动浏览器调研、当前代码盘点和反方审查。关键结论是复用现有阅读器/KaTeX及已有后端能力，另建严格的来源映射、答案版本和教学步进，不直接把自动解题循环或整站 iframe 当作符合用户需求。

DeepTutor 的材料 revision 与普通笔记 revision，不自动等于永久可回看的答案版本；服务器已保存，不等于手机已下载；提示词不改教材，不等于服务没有写教材的权限。这些是尚待实现验证的边界。

原始调研日期和来源 URL 均保留。新 AI 只在需要实施且资料可能已变时，针对关键接口重新查官方资料，不必重跑整轮互联网搜集。

## 环境重建线索

本项目 pyproject 声明 Python `>=3.12,<3.13`，运行依赖故意放在 requirements.lock 等既有文件，不能只执行一个无依赖的 pip install 就声称安装齐全。Node 依赖使用项目锁文件，本包不附 node_modules。

`交接资料/环境与模型重建/` 保留已使用环境的包版本、原生工具来源及模型清单。当前本地 TTS/ASR 使用 MLX，具有平台条件；新电脑上的 AI 应自行检查目标系统，再决定复用该路径还是适配其它后端。本包没有要求现在的用户提供电脑参数，也没有保证任意系统都原样运行 Mac 二进制。

已有 Mac 迁移适配参考包括包内动态路径、字体、TeX、Harness 位置和 Pango 字体后端。一次实际测试曾出现“程序自检通过但中文全是方框”，最终切到 Fontconfig 后才正常。因此零异常或非空图片不代替实际查看中文与公式画面。

不得携带或寻找旧电脑的登录 Cookie/密钥来冒充新环境已鉴权；按接手电脑已有授权与配置正常接入。项目内 fake/fixture 凭据仅为测试，不应当作可用账号。

## 接手后怎样继续

1. 读取交接入口、需求和状态，查看 Git HEAD/status、当前配置以及要处理模块的真实文件。
2. 根据用户的新指令选一个明确任务。若是继续正文，先检查对应原文、现稿及媒体；若是视频，直接读取已有 job/revision/source；若是内嵌 AI，先看最新交叉审查。
3. 仅重建该任务需要的环境与依赖，利用已有锁文件和模型来源。不要先下载上百 GB 的研究替代模型。
4. 对修改运行有针对性的真实验证，保留来源和版本。已有成品、接口存在、环境可导入、模型自评、数学语义验收分别报告。
5. 不把只调研的任务擅自改成实施；也不要对明确要求实施的任务只给计划。不要重新询问已经在资料与用户说明中能查到的内容。

## 读取资料时避免无效消耗

最新教材 `book/data/data.js` 约114 MiB，含音频base64与重复来源目录。不要整文件输出到模型上下文，也不要用会输出整行的普通搜索命令扫它。用本地脚本解析后只读所需单元、正文、来源或媒体字段；先查索引再看具体原片/截图。

Git历史按模块和提交查，研究报告按当前任务查。未提交的research文件应从工作树一起读取，不能只用git archive判断有什么。历史日志里残留的本机PID、localhost端口和用户目录不是接手电脑的当前状态，不应直接据此杀进程或写同一路径。
