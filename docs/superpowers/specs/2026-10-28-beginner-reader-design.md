# 复变函数初学者阅读器改进

用户已讨论并授权开始实施，保留完整原程序压缩包作为基线；当前目录为解包后的独立副本，无 Git 仓库。

## 已确认要求

1. 所有结论的证明默认折叠，包括正文夹带证明；结论、条件、直观解释继续显示。所有例题的题干、思路、步骤与答案整体默认折叠。内容保留，展开可读。
2. 疑惑点与可操作图像逐项对应；支持自由旋转、缩放、平移、修改参数和复位。覆盖复数、映照、积分、调和、级数、奇点、开拓、保形和拉氏变换，不以静态视频代替可操作场景。
3. 用户选定浅色正文＋深色图像区，保留原生 HTML/JS/CSS 与离线阅读能力。
4. 增加动画，现有与新增动画可配中文讲解；音频与步骤、字幕同步，可暂停、重播、调音量。

## 实施选择

- 继续使用现有引擎、ReaderDocument 和本地静态资源；不引入整套 React 迁移。
- 图像使用本地 Three.js，给每个目标绑定可配置场景；按可见性挂载并及时释放资源。
- 配音采用可替换宿主语音适配器；本机使用可用中文系统音色生成真实音频，以便立即验收，服务端语音可通过适配器替换。
- 原教材与原始运行记录不覆盖。新的改进阅读包另建目录，恢复双曲函数正确历史修订时保留来源证据。
- 修改生成、审核、展示与测试口径；不以隐藏整节、删正文或降低测试标准实现折叠。

## 验收

- 初始页面看不到任何证明正文和例题内部内容；用户点击后可完整读取。
- 图像与当前概念/方法有明确对应；控件真正改变曲面、轨迹或数值；旋转后可复位。
- 浅深分区在桌面与窄屏可读；公式和折叠内容不丢失。
- 生成实际中文音频，导出视频保留音轨；分步播放不会串音、越过下一步或丢失暂停状态。
- 新包可以离线使用；记录图像绑定覆盖和音频覆盖，不将未完成项伪报为完成。
