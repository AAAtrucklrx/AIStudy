# 可直接使用的视频解析

用户再次强调视频解析功能。现有产物仅为同视频技术试验、已整理的第一讲和视频证据导入/回看；缺少工作台选择视频后自动完成识别与讲解的流程。用户先前已授权自主决策与并行完成，不再请求常规方案批准。

目标：工作台能选择本地教学视频或使用已提供第一讲；提交后有阶段进度、失败/取消/恢复记录；自动得到带时间窗口的真实语音转写、关键帧与画面文字、公式与连续讲解，点击来源可回到原片。保留原始结果及不确定项，模型总结不能覆盖原始识别稿。用第一讲19分31秒实际从视频处理到结果，不能导入人工整理旧结果冒充新运行。

技术选择：本地Qwen ASR与Apple Vision OCR已可用，复用其环境和固定模型；原片经FFmpeg提取音频及有时间标识的帧。配置好的Harness账户传输用于关键帧理解、联合整理与审核；无新API密钥。保持可恢复、取消可停止子进程；模型调用和来源身份可追踪。采用生产可读配置指向现有依赖，不打包模型权重或账号。

结果分层：连续讲解、时间目录、逐窗转写、原帧/识别内容、公式与疑问、执行记录。视频为独立课程，不能自动归入复变教材。初版默认分析完整输入时长，抽帧覆盖与识别缺陷明确记录；不承诺每帧或所有口述被完全理解。相同视频结果缓存需绑定内容与运行配置，并可显式重新分析。

工作台沿用只限本机、同源与启动令牌保护。文件上传流式写入受控目录；不得提供任意路径写入或shell。产物只从任务目录内读取，HTML结果不获得管理权限。原书服务8766保持可读；视频工作台使用本机18916。
