### 2.5.1 幂函数

设 $n$ 是大于1的自然数，幂函数
$$w = z ^ {n}$$
定义在整个闭复平面上，把 $z = 0$ 及 $\infty$ 分别映为 $w = 0$ 及 $\infty$。它在有限复平面上解析，且 $w' = nz^{n-1}$。当 $w \neq 0$ 及 $\infty$ 时，由
$$z = \sqrt [ 3 ]{w} = \sqrt [ 3 ]{| w |} \exp \left(i \frac {\arg w + 2 k \pi}{n}\right), \quad k = 0, 1, 2, \dots , n - 1,$$
得知(这里  $\exp(i\theta)$  即是  $e^{i\theta}$ )，w 有 n 个原像。即  $w = z^{n}$  在有限复平面上不是——映照。下面先研究它在怎样的区域是单叶的。设有两个不同点  $z_{1} = r_{1}e^{i\theta_{1}}$  及  $z_{2} = r_{2}e^{i\theta_{2}}$  经  $w = z^{n}$  映照成同一点，即
$$r _ {1} ^ {n} \mathrm{e} ^ {\mathrm{i} n p _ {1}} = r _ {2} ^ {n} \mathrm{e} ^ {\mathrm{i} n p _ {2}}.$$
$$r _ {1} = r _ {2}, \quad n \varphi_ {1} = n \varphi_ {2} + 2 k _ {\pi}, \quad k \text {为任一整数}$$
$$r _ {1} = r _ {2}, \quad \varphi_ {1} = \varphi_ {2} + k \frac {2 \pi}{n}.\tag{2.8}$$
反之，映照 $w = z^{n}$ 把任何两个满足(2.8)式的点 $z_{1}$ 及 $z_{2}$ 变为同一点.这就是说， $w = z^{n}$ 是区域 $D$ 内的一一映照的充分必要条件是： $D$ 内不得含有任何两个满足条件
$$\mid z _ {1} \mid = \mid z _ {2} \mid , \quad \arg z _ {1} = \arg z _ {2} + k   {\frac {2 \pi}{n}}, \quad k \neq 0   \text {是整数}$$
的点 $z_{1}$ 和 $z_{2}$.
由上讨论可知， $z$ 平面上的任何一个以原点为顶点而跨度不大于 $2\pi /n$ 的角域
$$\alpha <   \arg z <   \beta , \quad \beta - \alpha \leqslant 2 \pi / n$$
都是变换 $w = z^n$ 的单叶性区域. 现在我们把函数 $w = z^n$ 的定义域限制在这个角域上, 令 $z = r e^{i\varphi}$, 则
$$w = z ^ {n} = r ^ {n} \mathbf {e} ^ {i m \varphi}.$$
现设 z 在此角域内的一条射线 L（不包括原点）； $\varphi = a_{0} \cdot a < a_{0} < \beta$  变动，那么  $w = r^{*} \exp(ina_{0})$ 。于是  $|w| = r^{*}, 0 < r + \infty$  从  $(不包括0)$  增大到  $+\infty$ ，而  $\arg w = na_{0}$  构不变。因此，w 就相应地描出一条射线 L1； $\arg w = na_{0}$  （不包括 w = 0）。如果证上从  $\alpha$  （不包括  $\alpha$ ）递增时  $\beta$  （不包括  $\beta$ ），这射线 L 将按反针方向扫过角域  $<\alpha \exp(\beta$  图  $(2)$  图  $(2)$ ，相应的  $\arg w = na_{0}$  。从  $n_{4}$  （不包括  $n_{4}$ ）递增到  $n_{3}$  （不包括  $n_{3}$ ），射线 L1 按按反针方向扫过角域  $<\arg w < n_{3}$ ；由此可见，w = z* 确定从角域  $<\alpha \exp(\beta, -\beta, -\alpha \leqslant 2\pi / n$  到角域  $<\alpha \arg w < n_{3}$  的单叶映照：由  $|w| = |z|^{\star}$ ，可见这个映照把位于角域  $<\alpha \exp(\beta < \alpha$  中的一段圆弧  $|z| = R_{7}$ ，变为角域  $<\alpha \arg w < n_{3}$  中的一段圆弧； $w = R_{7}^{*}$ ，特别地，w = z* 把角域  $0 < \alpha z < n/ \pi$  单叶地截起上半 × 平面  $0 < \alpha \arg w < n_{3}$ 。

角域的一边 $\arg z = -\pi / n$ 映为 $w$ 平面的负实轴的下岸 $\arg w = -\pi$，另一边
$\arg z = \pi / n$ 映为 $w$ 平面的负实轴的上岸 $\arg w = \pi$. 由于 $w = z^n$ 把定义域限制在角域 $-\pi / n < \arg z < \pi / n$ 是单叶函数, 由此可以定义它的一个单值反函数, 我们把它记作 $z = (\sqrt[n]{w})_0$, 它把沿负实轴割开了的 $w$ 平面 $-\pi < \arg w < \pi$ 映成角域 $-\pi / n < \arg z < \pi / n$. 由复数的开方运算可知, 这个反函数的表达式是
$$z = (\sqrt [ n ]{w}) _ {0} = \sqrt [ n ]{| w |} \exp \left(\mathrm{i} \frac {\arg w}{n}\right), - \pi <   \arg w <   \pi .$$
同样，角域 $D_{1}: \pi / n < \arg z < 3\pi / n$ ，被单叶地映成区域 $\pi < \arg w < 3\pi$ ，这仍是一个去掉了负实轴的 $w$ 平面。一般地，$w = z^{n}$ 把角域 $D_{k}$ ：
$$\frac {2 k - 1}{n} \pi <   \arg z <   \frac {2 k + 1}{n} \pi , \quad k = 0, 1, 2, \dots , n - 1$$
单叶地映照成沿负实轴割开了的 $w$ 平面 $(2k - 1)\pi < \arg w < (2k + 1)\pi.$ 于是，把 $w = z^n$ 的定义域限制在角域 $D_{k}$ 上就可以确定出相应的单值反函数
$$z = (\sqrt [ n ]{w}) _ {k} = \sqrt [ n ]{| w |} \exp \left(\mathrm{i} \frac {\arg w}{n}\right), (2 k - 1) \pi <   \arg w <   (2 k + 1) \pi .$$
这样，每一个单值函数 $z = (\sqrt[n]{w})_k$ 都把沿负实轴割开了的 $w$ 平面变成相应的角域$D_{k}$ .依习惯用 $z$ 作自变量.图2.6画出了 $n = 6$ 时，函数 $w = (\sqrt[n]{z})_k$ 的对应关系.
