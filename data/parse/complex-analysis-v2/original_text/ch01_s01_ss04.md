### 1.1.4 复数的乘方和开方

设 $n$ 是正整数，$z^n$ 表示 $n$ 个 $z$ 的乘积。当 $z = 0$ 时，$z^n = 0$。当 $z \neq 0$ 时，设 $z = r e^{i\varphi}$，由乘法规则，得
$$z ^ {n} = r ^ {n} \mathrm{e} ^ {\mathrm{i} m \varphi} = r ^ {n} (\cos n \varphi + \mathrm{i} \sin n \varphi).\tag{1.4}$$
显然，上式对 $n = 0$ （定义 $z^{\circ} = 1$）时也成立.如果定义
$$z ^ {- n} = \frac {1}{z ^ {n}},$$
$$z ^ {- n} = r ^ {- n} [ \cos (- n \varphi) + \mathrm{i} \sin (- n \varphi) ] = r ^ {- n} \mathrm{e} ^ {- i n \varphi}.\tag{1.5}$$
特别地，在(1.4)及(1.5)式中，令 $r = 1$ ，得
$$(\cos \varphi + \mathrm{i} \sin \varphi) ^ {n} = \cos n \varphi + \mathrm{i} \sin n \varphi .$$
这个公式称为德·莫弗(de Moivre)公式，它对任意整数 $n$ 都成立.
设 $z$ 为已给复数，方程
$$w ^ {n} = z\tag{1.6}$$
的所有解，称为 $z$ 的 $n$ 次方根，记作 $\sqrt[n]{z}$ 当 $z = 0$ 时，方程(1.6)只有唯一解 $w = 0$ 当 $z \neq 0$ 时，设 $z = r\mathrm{e}^{i\varphi}, w = \rho \mathrm{e}^{\mathrm{i}\varphi}$，代入(1.3)式，并利用德·莫弗公式，得
$$\rho^ {n} \mathrm{e} ^ {\mathrm{i} \omega t} = r \mathrm{e} ^ {\mathrm{i} \varphi},$$
再比较两端得
$$\rho^ {n} = r, \quad n \theta = \varphi + 2 k \pi , \quad k = 0, \pm 1, \pm 2, \dots .$$
由于 $\rho$ 和 $r$ 都是正实数，故由第一式即可唯一确定 $\rho$ ，并记之为
$$\rho = (\sqrt [ n ]{r}),$$
其中，圆括号表示 $\rho$ 是 $r$ 的唯一正实根（算术根）.由第二式可得
$$\theta = \frac {\varphi + 2 k \pi}{n}.$$
由此即得出公式
$$\sqrt [ n ]{z} = (\sqrt [ n ]{r}) \left(\cos \frac {\varphi + 2 k \pi}{n} + \mathrm{i} \sin \frac {\varphi + 2 k \pi}{n}\right).$$
这个公式里 k 虽然可以取任意整数，但所得出的复数只有 n 个是互不相同的，即相当于  $k = 0, 1, 2, \cdots, n - 1$  的情形：
$$w _ {0} = (\sqrt [ n ]{r}) \left(\cos \frac {\varphi}{n} + \mathrm{i} \sin \frac {\varphi}{n}\right),$$
$$w _ {1} = (\sqrt [ n ]{r}) \left(\cos \frac {\varphi + 2 \pi}{n} + \mathrm{i} \sin \frac {\varphi + 2 \pi}{n}\right),$$
$$w _ {n - 1} = (\sqrt [ n ]{r}) \left[ \cos \frac {\varphi + 2 (n - 1) \pi}{n} + \mathrm{i} \sin \frac {\varphi + 2 (n - 1) \pi}{n} \right].$$
这 $n$ 个 $n$ 次根的模都是 $(\sqrt[n]{r})$，因此它们都位于以原点为中心，$(\sqrt[n]{r})$ 为半径的圆上。且由于相邻二根的辐角相差都是 $2\pi / n$，所以这 $n$ 个点刚好把圆周分成 $n$ 等分。它们是内接于圆的正 $n$ 边形的顶点。
加、减、乘、除、开方及乘方这六种运算合称为代数运算.从以上的讨论可见，在复数域内代数运算是通行无阻的(除了除法要求分母不为零)，这是复数域与实数域的一个重要区别.
例9 求 $\sqrt[3]{-8}$ 的全部值.
解 把 -8 表成三角形式为： $-8 = 2^{3}(\cos\pi + \mathrm{i}\sin\pi)$ ，则
$$\sqrt [ 3 ]{- 8} = 2 \Big (\cos \frac {\pi + 2 k \pi}{3} + \mathrm{i} \sin \frac {\pi + 2 k \pi}{3} \Big), \quad k = 0, 1, 2,$$
$$\sqrt [ 3 ]{- 8} = \left\{ \begin{array}{l l} 1 + \mathrm{i} \sqrt {3}, & k = 0 \\ - 2, & k = 1 \\ 1 - \mathrm{i} \sqrt {3}, & k = 2. \end{array} \right.$$
