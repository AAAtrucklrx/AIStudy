### 9.2.4 本函数的积分法

设 $\mathrm{L}[f(t)] = F(p)$，则
$$\mathrm{L} \left[ \int_ {0} ^ {t} f (t) \mathrm{d} t \right] = \frac {F (p)}{p}.$$
证 记 $\varphi(t) = \int_{0}^{t} f(t) \, \mathrm{d}t$，则 $\varphi'(t) = f(t)$，由本函数的微分法，有
$$\mathrm{L} \left[ \varphi^ {\prime} (t) \right] = p \mathrm{L} [ \varphi (t) ] - \varphi (0) = p \mathrm{L} [ \varphi (t) ].$$
$$\mathrm{L} \left[ \varphi^ {\prime} (t) \right] = \mathrm{L} [ f (t) ] = F (p),$$
$$\mathrm{L} \left[ \int_ {0} ^ {t} f (t) \mathrm{d} t \right] = \frac {F (p)}{p}.$$

例6 如图9.1所示电路，设 $t = 0$ 时电容器上没有电荷，求电流 $i(t)$
解 因为 t = 0 时, 电容器上没有电荷. 由回路电压定律, 得电路方程
$$R i (t) + \frac {1}{C} \int_ {0} ^ {t} i (t) d t = E.$$
设 $\mathrm{L}[i(t)] = I(p)$，对上式两端作拉氏变换，并利用上述积分性质，得
$$R I + \frac {1}{C p} I = \frac {E}{p},$$
$$I (p) = \frac {E}{p} / \left(R + \frac {1}{C p}\right) = \frac {E}{R \left(p + \frac {1}{C R}\right)}.$$
再作逆变换，得
$$i (t) = \mathrm{L} ^ {- 1} [ I (p) ] = \frac {E}{R} \mathrm{L} ^ {- 1} \left[ \frac {1}{p + \frac {1}{C R}} \right] = \frac {E}{R} \mathrm{e} ^ {- t / C R}.$$
这就是 R-C 充电过程的电流的变化规律.
